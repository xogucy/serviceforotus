# notification-service

Отвечает за уведомления.

## Задачи

- Читать события результата оплаты из Kafka.
- Сохранять уведомления в БД.
- Отдавать список уведомлений пользователя через HTTP API.

## Минимальное API

```http
GET /notifications/{userId}
```

## Интеграции

```text
Kafka -> notification-service: consume OrderPaymentResult
```

## Правила

- Реальная отправка email не выполняется.
- Уведомление только сохраняется в БД.
- Сохраняются и успешные, и неуспешные уведомления.
